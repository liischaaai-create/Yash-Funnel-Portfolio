# Yash Agarwal | Funnel Designer Portfolio

Static portfolio site (HTML, CSS and JavaScript, no build step).

- `index.html`: the page
- `styles.css`: styles
- `main.js`: animations and interactions
- `images/`: profile photo and Selected Work previews (`images/work/`)

## Run locally

```
python -m http.server 5500
```

Then open http://localhost:5500/

## Deploy

Hosted on Vercel. Framework preset: **Other**, no build command, output directory: repository root.
